1 设计题目

课题4：英文电子词典。

功能要求（按课程任务书）
1) 添加单词
2) 修改单词
3) 删除单词
4) 查询单词（英文->中文、中文->英文）
5) 浏览全部单词
6) 随机查看单词（中文提示，用户输入英文拼写，正确显示“Good job!”，错误显示“Try again!”）

数据要求：使用泛型集合存储单词信息（英文、中文），至少包含50个单词；可保存在文本文件中并在程序启动时读取。


2 目的与要求

本课程设计旨在：
- 熟练使用 Java 面向对象技术完成一个中等规模的应用程序；
- 掌握文件读写、集合、异常处理及简单 Swing GUI 编程；
- 按课程设计要求撰写设计说明书并完成测试。

交付物：软件代码一份（包括测试数据 dictionary.txt）、课程设计报告（本文件，DOCX 与 Markdown 格式），运行说明与截图。


3 概要设计

3.1 功能模块设计

系统共分为以下模块：
- 数据存储模块：负责从 dictionary.txt 加载、保存词典；使用 TreeMap<String,String> 存储（键：英文，值：中文）。
- 界面模块（GUI）：基于 Swing，实现添加/修改/删除/查询/浏览/拼写测试等交互功能。
- 业务逻辑模块：实现对 dict 集合的增删改查、统计和拼写测试的逻辑。
- 辅助模块：输入校验、UI 状态管理（显示/隐藏按钮）、文件存在性检查。

3.2 系统流程

主要流程（文本描述）：
1) 程序启动：调用 loadDictionary() 从工作目录下的 dictionary.txt 读取词条到 TreeMap。若文件不存在，调用 saveDictionary() 创建空文件。
2) 主界面显示：侧边导航按钮用于选择操作模式（添加/修改/删除/查询/浏览/拼写测试）。
3) 用户操作：根据模式使用文本框和按钮提交请求，程序在内存集合上操作并在必要时调用 saveDictionary() 持久化。
4) 拼写测试流程：随机选择一个单词（英文键），显示中文解释，用户在英文输入框输入答案，点击检查按钮显示结果；可点击“下一个”切换下一条。

4 详细设计

4.1 算法思路

- 读取文件：逐行读取 dictionary.txt，每行按照第一个等号 "=" 分割为英文和中文并放入 TreeMap。使用 BufferedReader，优先跳过空行和格式不正确的行。
- 添加/修改：先做输入校验（非空、无等号、无换行、英文单词不含空格、长度限制），再更新 map 并保存。
- 删除：检查单词是否存在，从 map 中移除并保存。
- 查询：优先按英文键直接查找；若英文输入为空且中文输入非空，则遍历 map 查找包含该中文文本的值并返回所有匹配项。
- 拼写测试：取 keySet 数组随机索引获取单词，记录为 currentAnswer，显示对应中文，输入英文后比较 equals 判断是否正确。

4.2 类说明

主类：dictionary（现有实现名为小写，但建议改为 Dictionary）
主要成员变量（摘要）：
- Map<String,String> dict — 词典数据（TreeMap 保持键升序）
- 多个 Swing 组件：JTextArea display, JTextField engField, meanField; JButtons add/edit/delete/search/view/random/next 等

主要方法：
- main(String[]): 程序入口，初始化 GUI 并在启动时加载词典
- loadDictionary(): 从 dictionary.txt 加载到 TreeMap
- saveDictionary(): 将当前 TreeMap 写回 dictionary.txt
- addWord(), editWord(), deleteWord(), searchWord(), viewAll(): 对应功能实现
- startQuiz(), checkAnswer(), nextQuiz(): 拼写测试逻辑
- isValidInput(): 输入校验
- allHide(), allShow(): 用于控制不同模式下的组件可见性

4.3 数据存储与持久化

- 文件格式：每行英文=中文，例如：apple=n. 苹果
- 程序在当前工作目录寻找 dictionary.txt；若不存在则创建空文件。
- 建议：将文件放在程序运行目录（或指定的 resources/ 目录），并确保有读写权限。


5 测试

测试用例（示例）：

6 部署与运行说明

环境要求：
- JDK 8 或更高（推荐 JDK 11+）
- 操作系统：Windows / Linux / macOS 都可运行（需安装 JRE）

编译运行（命令行）
1) 在项目根目录执行：javac -encoding UTF-8 dictionary.java
2) 运行：java dicy.dictionary

若使用 IDE（推荐 IntelliJ IDEA 或 Eclipse）：
- 将项目作为 Java 项目导入；确保 package 声明 dicy 与源文件路径匹配（src/dicy/dictionary.java）。
- 运行 main 函数。

注意：程序在运行时会读取/写入当前工作目录下的 dictionary.txt，请保证该目录可写。

B. 已知问题与改进建议
1) searchWord() 方法中的中文查询逻辑存在一个花括号/循环错误：当前实现将 found 判断与 display 更新放在循环内，导致未找到时逻辑异常。建议将 found 判断与 display 更新移到循环之外。
2) engField 在 main 中被重复创建并多次添加到 JFrame，这会造成冗余（重复的组件引用）。建议删除重复创建，只创建一次并在需要的地方设置可见/可编辑状态。
3) 类名使用小写（dictionary）不符合 Java 命名习惯，建议重命名为 Dictionary（类名首字母大写）并把文件名改为 Dictionary.java。
4) Swing GUI 的创建应当在事件分发线程（EDT）中执行：使用 SwingUtilities.invokeLater(...) 来启动 GUI。当前直接在 main 线程构建 UI，风险较小但不规范。
5) 建议改用布局管理器（如 BorderLayout + JPanel/GridBagLayout）替代 null 布局，保证不同平台与分辨率下的可用性。
6) 持久化路径建议支持配置，或将 dictionary.txt 放在 resources/ 并支持相对路径或用户主目录下的应用数据目录。
